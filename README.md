# Voice Assistant for MIK32 "Amur"

Голосовой ассистент на базе микроконтроллера MIK32 "Amur" (ELBEAR ACE-UNO) с поддержкой управления RGB-лентой, воспроизведения звука через DFPlayer Mini и чтения температуры/влажности с датчика DHT11.

## 🎯 Возможности

- Голосовое управление светом (вкл/выкл)
- Управление RGB-лентой
- Режим "Ночник" (тёплый жёлтый свет)
- Голосовой запрос температуры и влажности
- Аудиоответы через DFPlayer Mini
- Визуальные эффекты при ответе (радуга)

## 🔧 Аппаратные компоненты

| Компонент | Модель | Назначение |
|-----------|--------|------------|
| Микроконтроллер | MIK32 "Амур" (ELBEAR ACE-UNO) | Главный процессор |
| Модуль распознавания речи | DF2301Q | Голосовые команды |
| MP3-плеер | DFPlayer Mini | Воспроизведение ответов |
| Датчик температуры/влажности | DHT11 | Измерение климата |
| RGB-лента | WS2812 или аналог | Световые эффекты |
| MOSFET модуль | AOD4184 (x3) | Управление RGB-лентой (PWM коммутация) |
| Блок питания | AC/DC адаптер 12V | Питание RGB-ленты |


## 🎤 Команды голосового ассистента

| Команда (русский) | Команда (английский) | Действие |
|------------------|---------------------|----------|
| "Амур" / "Привет робот" | "Hello robot" | Активация (wake word) |
| "Включи свет" | "Turn on the light" | Включить белый свет |
| "Выключи" | "Turn off the light" | Выключить свет |
| "Красный свет" | "Set to red" | Красный цвет |
| "Зелёный свет" | "Set to green" | Зелёный цвет |
| "Синий свет" | "Set to blue" | Синий цвет |
| "Режим Ночник" | "Moonlight mode" | Тёплый жёлтый свет |
| "Какая температура?" | "Read temperature" | Озвучить температуру |
| "Какая влажность?" | - | Озвучить влажность |


## 🛠️ Установка и сборка

### Требования

- Docker (рекомендуется) или установленный RISC-V toolchain
- CMake 3.28+
- OpenOCD (для прошивки)

### Сборка

```bash
# Клонирование репозитория
git clone --recursive https://github.com/your-repo/voice-assistant.git
cd voice-assistant

# Инициализация submodule
git submodule update --init --recursive

# Сборка проекта
./build.sh

# Прошивка устройства
./flash.sh
```

## 🔌 Схема подключения

### DF2301Q (голосовой модуль) - UART1

| DF2301Q | ELBEAR (МИК32) |
|---------|----------------|
| VCC     | 3.3V / 5V      |
| GND     | GND            |
| D/T     | D7 (PORT 1.8)  |
| C/R     | D8 (PORT 1.9)  |

**Переключатель на модуле:** положение **UART**

### DFPlayer Mini (аудиоплеер) - UART0

| DFPlayer | ELBEAR (МИК32) |
|----------|----------------|
| VCC      | 5V             |
| GND      | GND            |
| TX       | D0 (PORT 0.5)  |
| RX       | D1 (PORT 0.6)  |

### RGB-лента (PWM)

| RGB-лента | ELBEAR (МИК32) |
|-----------|----------------|
| R         | D5 (PORT 0.1)  |
| G         | D6 (PORT 0.2)  |
| B         | D9 (PORT 0.3)  |

### DHT11 (датчик температуры/влажности)

| DHT11 | ELBEAR (МИК32) |
|-------|----------------|
| VCC   | 3.3V           |
| GND   | GND            |
| DATA  | D11 (PORT 1.1) |
